# 傳檔到雲端硬碟 — 安裝說明

在 Android 手機的任何 App（相簿、LINE、檔案管理…）按「分享」→ 選「傳檔」，檔案就會**自動上傳**到你自己 Google 雲端硬碟裡的「傳檔」資料夾，不用每次選資料夾。

整套系統完全免費、不需要伺服器，分成兩部分：

| 部分 | 放在哪裡 | 作用 |
|---|---|---|
| Apps Script（`apps-script/Code.gs`） | 你自己的 Google 帳號 | 收檔案、存進「傳檔」資料夾 |
| 網頁 App（其餘檔案） | GitHub Pages，例如 `https://pphhxx2.github.io/physics-simulations/share-to-drive/` | 手機上的「傳檔」App，出現在分享選單 |

---

## 第一步：建立 Apps Script（約 5 分鐘，只做一次）

1. 用電腦開啟 <https://script.google.com>，登入要存檔的 Google 帳號。
2. 按左上角「**新專案**」。
3. 把編輯區原本的內容全部刪掉，貼上 `apps-script/Code.gs` 的全部內容。
4. 左上角「未命名的專案」改名為「傳檔」，按 💾 儲存（或 Ctrl+S）。
5. 上方函式下拉選單選「**setup**」，按「**▶ 執行**」。
6. 會跳出「需要授權」：
   - 按「審查權限」→ 選你的帳號。
   - 若出現「Google 尚未驗證這個應用程式」：按「**進階**」→「**前往「傳檔」（不安全）**」。（這是你自己寫的程式，所以 Google 沒有審核，放心）
   - 按「**允許**」。
7. 下方會出現「**執行紀錄**」，裡面有一行：
   `你的金鑰（SECRET KEY）：xxxxxxxx……`
   把這串金鑰複製起來（等一下要用）。
   - 同時雲端硬碟的「我的雲端硬碟」裡會自動出現「傳檔」資料夾。
   - 忘記金鑰：再執行一次 `setup()` 就會再印出同一把金鑰。

## 第二步：部署成網頁應用程式

1. 右上角按「**部署**」→「**新增部署作業**」。
2. 左邊齒輪 ⚙️「選取類型」→ 選「**網頁應用程式**」。
3. 設定：
   - 說明：隨意，例如「傳檔」
   - **執行身分：我**
   - **具有存取權的使用者：所有人**（一定要選這個，手機才連得到；有金鑰保護，別人無法亂傳）
4. 按「**部署**」，複製「**網頁應用程式網址**」（以 `https://script.google.com/macros/s/` 開頭、`/exec` 結尾）。

> 之後如果修改了 Code.gs：選「部署」→「管理部署作業」→ ✏️ 編輯 →「版本」選「新版本」→ 部署。這樣網址不會變。

## 第三步：在 Android 手機安裝「傳檔」App

1. 用手機的 **Chrome** 開啟網頁 App 網址（例如 `https://pphhxx2.github.io/physics-simulations/share-to-drive/`）。
2. 第一次開啟會出現「設定」：
   - 「網頁應用程式網址」貼上第二步的網址
   - 「金鑰」貼上第一步的金鑰
   - 按「**測試連線**」，看到「連線成功 ✅」後按「**儲存**」。
   - 小技巧：可以先在電腦把網址和金鑰用 LINE／Email 傳給自己，再到手機複製貼上。
3. 按 Chrome 右上角「⋮」→「**安裝應用程式**」或「**新增至主畫面**」→ 安裝。
4. 主畫面會出現藍色雲朵圖示「傳檔」。

## 第四步：開始使用

- **從其他 App 分享**：在相簿選照片／影片 → 按「分享」→ 選「**傳檔**」→ App 自動開啟並上傳，每個檔案顯示進度與 ✅／❌，完成後顯示「已上傳 N 個檔案到「傳檔」」，可按「開啟「傳檔」資料夾」查看。
  - 第一次安裝後，「傳檔」可能要過幾秒才會出現在分享選單；若沒看到，可在分享選單按「更多」尋找，或重新開機。
- **分享網址或文字**：會存成一個 `分享文字-日期時間.txt` 檔。
- **失敗了**：按「🔄 重試失敗的檔案」。沒上傳成功的檔案會留在手機裡，下次開 App 也會自動續傳。
- **同名檔案**：不會覆蓋，會自動在檔名前加上時間，例如 `20261024-181500-照片.jpg`。
- **畫質**：預設上傳原檔，不壓縮。若想省流量，可在「⚙️ 設定」勾選「上傳前壓縮照片」。

## iPad／電腦怎麼用

iPhone／iPad 的 Safari 和電腦瀏覽器**不支援**把網頁 App 加到分享選單，但仍可：
- 直接開啟網頁 App，按「**選擇檔案上傳**」，或（電腦）把檔案**拖曳**到虛線框內。
- iPad 可用 Safari 的「分享」→「加入主畫面」，以後點圖示開啟更方便。
- 每台裝置第一次使用都要輸入一次網址和金鑰（只存在那台裝置上）。

## 限制

- 單一檔案上限約 **35 MB**（Google Apps Script 的限制）。超過的影片請改用 Google 雲端硬碟 App 上傳。
- Google 免費帳號的 Apps Script 每天有使用次數與執行時間上限，一般老師日常使用不會碰到。
- 需要網路；大檔案用行動網路會比較慢。

## 安全性說明

- 網頁應用程式設為「所有人」可存取，但**沒有正確金鑰的請求一律拒絕**，所以別人就算知道網址也無法上傳到你的雲端硬碟。
- 這個程式只會**新增**檔案到「傳檔」資料夾，不會讀取、刪除你其他的檔案（雖然授權畫面寫的是雲端硬碟權限）。
- 金鑰請不要公開（例如不要貼在 GitHub 或公開網頁上）。網頁 App 本身不含金鑰，金鑰只存在你自己的手機瀏覽器裡。
- 若懷疑金鑰外洩：在 Apps Script 選函式「**resetKey**」執行，到執行紀錄複製新金鑰，再到每台裝置的「⚙️ 設定」更新即可，舊金鑰立即失效。
- 若想完全停用：Apps Script「部署」→「管理部署作業」→ 封存。

## 檔案清單

```
share-to-drive/
├── index.html              網頁 App 畫面
├── app.js                  上傳、設定、佇列、重試邏輯
├── sw.js                   Service Worker（接收分享、離線快取）
├── manifest.webmanifest    App 資訊與分享目標設定
├── icons/                  App 圖示（192、512、maskable 512）
├── apps-script/Code.gs     貼到 script.google.com 的後端程式（不必上傳到 GitHub）
└── README-安裝說明.md       本說明
```

上傳到 GitHub Pages 時，把整個 `share-to-drive` 資料夾放進 repo 即可（所有路徑都是相對路徑，放在任何子資料夾都能用）。
